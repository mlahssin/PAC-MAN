pyinstaller :
    PyInstaller packages your game  
    so players don’t need to install Python or dependencies.
    PAC-MAN: the executable that starts the game.
    _internal/: bundled Python runtime, libraries, assets and configuration.

install it :
    uv add pyinstaller


uv run pyi-makespec \
  --name PAC-MAN \
  --onedir \
  --add-data "assets:assets" \
  --add-data "config.json:." \
  main.py


The .spec file is the recipe PyInstaller follows to build your game.

Entry point: main.py.
Extra files: assets/ and config.json.
Application name: PAC-MAN.
Build format: one folder containing the executable and supporting files.


uv run pyi-makespec \
  --name PAC-MAN \
  --onedir \
  --add-data "assets:assets" \
  --add-data "config.json:." \
  main.py



why we putted just the assets and the config file ??

Because PyInstaller finds Python code through imports automatically.

Starting from main.py, it follows imports to include app.py, scenes, game logic, Pygame, Pydantic, etc.

But images, fonts and JSON aren’t Python modules, so we explicitly include them:
- assets/ → images and fonts.
- config.json → default game settings.


uv run pyinstaller --clean PAC-MAN.spec






1. uv run runs PyInstaller in your project’s environment.
2. --clean clears PyInstaller’s cache and temporary build files.
3. PyInstaller reads PAC-MAN.spec for the packaging instructions.
4. It analyzes main.py and follows imports to collect your code and dependencies.
5. It bundles the Python runtime, libraries, assets/ and config.json.
6. It creates the executable and supporting files in dist/PAC-MAN/.
build/ contains working files; dist/ contains the finished application.
