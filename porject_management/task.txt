## TASK 01 — Refactor Game Initialization

- [ ] Create `initialize_level()` in the `Game` class.
- [ ] Move level-specific initialization from `__init__()` into this method.
- [ ] Keep global attributes in `__init__()`:
  - `self.level`
  - `self.score`
  - `self.lives`
  - `self.game_over`
  - `self.game_won`
- [ ] Call `initialize_level()` to initialize Level 1.

**Goal:** Avoid duplicating initialization code when switching levels.

---

## TASK 02 — Implement Maze Regeneration

- [ ] Keep maze width and height unchanged.
- [ ] Keep `perfect=False`.
- [ ] Use a fixed seed for Level 1.
- [ ] Change the seed for every subsequent level (random integer or `None` if supported).
- [ ] Generate a new `Maze` instance for every level.
- [ ] Verify that different seeds actually produce different maze layouts.
- [ ] Recalculate valid player and ghost spawn positions.
- [ ] Verify that all required collectible positions are reachable.

**Goal:** Each new level has a different playable maze.

---

## TASK 03 — Implement Ghost Difficulty Progression

- [ ] Move ghost `frames_per_cell` configuration out of the game loop.
- [ ] Make ghost speed configurable through the `Game` class.
- [ ] Adjust ghost speed according to the current level.
- [ ] Gradually decrease `frames_per_cell` to make ghosts faster.
- [ ] Define a minimum `frames_per_cell` to prevent excessive speed.
- [ ] Make ghost random movement frequency/probability configurable.
- [ ] Reduce random movements as the level increases.
- [ ] Use pure BFS chasing on Level 10 (no random moves).
- [ ] Test whether the final level is challenging but still playable.

**Example difficulty configuration (adjust after testing):**

| Level | Frames per cell | Random movements |
|---|---:|---:|
| 1 | 24 | 25% |
| 2 | 24 | 20% |
| 3 | 22 | 15% |
| 4 | 22 | 15% |
| 5 | 20 | 10% |
| 6 | 20 | 10% |
| 7 | 18 | 5% |
| 8 | 18 | 5% |
| 9 | 16 | 0% |
| 10 | 16 | 0% |

**Goal:** Progressively increase difficulty without rewriting the entire ghost AI.

---

## TASK 04 — Reset Collectibles

- [ ] Clear the previous level's gums and supergums.
- [ ] Regenerate normal gums based on the new maze.
- [ ] Regenerate four supergums at valid corner positions.
- [ ] Clear the previous level's collected-position tracking.
- [ ] Make sure every collectible can be reached.
- [ ] Ensure each collectible awards points only once.

**Goal:** Every new level starts with fresh collectibles.

---

## TASK 05 — Reset Player and Ghosts

- [ ] Create new player and ghost objects for each level, or reset existing objects completely.
- [ ] Put the player at the new valid starting position.
- [ ] Put the four ghosts at their corresponding valid spawn positions.
- [ ] Reset `target_pos`, `direction`, `requested_direction` and `previous_pos` where applicable.
- [ ] Set all ghost states to `DANGEROUS`.
- [ ] Reset every ghost's `respawn_time_at`.
- [ ] Reset the global `edible_active_unitl` timer.
- [ ] Apply the current level's ghost speed and AI configuration.

**Goal:** No movement state or ghost effect carries over from the previous level.

---

## TASK 06 — Reset Level-Specific State

- [ ] Set `self.level_completed = False`.
- [ ] Start a new level timer using `time.monotonic() + 180`.
- [ ] Ensure the timer starts when gameplay begins.
- [ ] Ensure pause/resume freezes the level timer and ghost timers.
- [ ] Preserve the player's current score.
- [ ] Preserve the player's remaining lives.

**Goal:** A new level starts cleanly without losing overall game progress.

## TASK 07 — Implement `next_level()`

- [ ] Check whether `self.level_completed` is `True`.
- [ ] Prevent repeated transitions from the same completed level.
- [ ] Check whether the current level is Level 10.
- [ ] If Level 10 is completed, set `self.game_won = True`.
- [ ] Otherwise, increment `self.level`.
- [ ] Call `initialize_level()` to prepare the next level.
- [ ] Ensure no Level 11 is generated.

**Goal:** Move correctly from Level 1 through Level 10.
